# How Computers Solve Differential Equations

This experiment compares three update rules for the harmonic oscillator
$q'=p$, $p'=-q$ on a fixed temporal grid. Each rule defines a one-step map
$x_{n+1}=\Psi_h(x_n)$, and the long-time approximation is generated by
composition.

The script implements exactly:

$$
\begin{aligned}
\text{explicit Euler: }&x_{n+1}=x_n+h f(x_n),\\
\text{implicit Euler: }&x_{n+1}=x_n+h f(x_{n+1}),\\
\text{implicit midpoint: }&x_{n+1}=x_n+h f((x_n+x_{n+1})/2).
\end{aligned}
$$

Because this ODE is linear, the implicit equations are solved directly with
`numpy.linalg.solve`. A tight-tolerance SciPy `DOP853` trajectory supplies the
reference.

## Run

From the repository root:

A system LaTeX installation is required for the repository's Matplotlib style.

```bash
python -m pip install -r requirements.txt
python video_02_classical_ode_solvers/run.py
```

The script creates
[`figures/white/harmonic_phase.png`](figures/white/harmonic_phase.png), a
white-background copy of the equal-aspect phase portrait from $(q_0,p_0)=(1,0)$
with $T=20$ and $h=0.1$, coupled with a tiny table of `time.perf_counter()`
integration timings. The transparent dark-slide version is saved in `figures/`.
It shows explicit Euler spiralling outward, implicit Euler spiralling inward,
and implicit midpoint remaining close to the reference orbit. This single
fixed-step example shows that different update rules can give qualitatively
different approximations; it does not by itself explain stability, order,
geometric integration, or robust performance benchmarking.
